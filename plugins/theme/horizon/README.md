# Horizon theme

Horizon is a componentized SolidJS and Ark UI theme for Snowglass's native
Deno/Blitz shell.

```powershell
npm install
npm run build
cargo run --bin snowglass-gui -- --theme horizon
```

For live development, use `--theme horizon --debug`; Snowglass will start the
theme's Vite server on port 5174.
