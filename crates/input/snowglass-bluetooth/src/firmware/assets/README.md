# Embedded Realtek Bluetooth firmware

The files in this directory come from the `rtl_bt` directory of the
linux-firmware project. Snowglass pins the source revision to:

`01205307636157a12c29e6a774bf83b218732050`

The firmware is redistributed under `LICENCE.rtlwifi_firmware.txt`. Symlinked
configuration files are represented once and selected through aliases in
`firmware/realtek.rs`.
